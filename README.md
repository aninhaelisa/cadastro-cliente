# cadastro-de-cliente
Sistema web para cadastro e gerenciamento de clientes, desenvolvido como projeto acadêmico utilizando Node.js, Express e MySQL.

## Sobre o projeto
O Cadastro de Clientes permite registrar informações pessoais e dados de endereço, consultar clientes cadastrados e visualizar relatórios com informações sobre os registros.<br>
O projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento web, integração entre front-end e back-end, manipulação de banco de dados e criação de APIs.<br>

## Funcionalidades
- Cadastro de clientes.
- Armazenamento dos dados no banco de dados MySQL.
- Listagem de clientes cadastrados.
- Edição dos dados dos clientes.
- Exclusão de registros.
- Relatório com o total de clientes cadastrados.
- Indicadores de cadastros realizados no dia e no mês.
- Visualização de informações para impressão.
- Página de suporte.
- Tratamento de respostas e mensagens do sistema.

## Tecnologias utilizadas
HTML5, CSS3, JavaScript, Node.js, Express, MySQL, mysql2 e dotenv.
